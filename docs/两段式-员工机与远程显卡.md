# 内容生产 · 两段式（员工主机剪 / 显卡服务器算）

> 一句话：**能用手剪的在员工机器上剪，吃显卡的活统一丢给一台 GPU 机器**，通过 huoke 网站的接口调用，人和 agent 用的是同一套接口。

```
素材 → 员工主机（mf + D剪）：整理 · 粗剪 · 字幕 · 包装 · 导出
                        ↘ 需要显卡的步骤（识别/翻译/配音/人声分离/视频生成）
                           → 远程 GPU 接口 → 结果回到工程目录
```

## 一、员工主机装什么（给剪辑同事）

### 必装

| 组件 | 用途 | 来源 |
|---|---|---|
| **ai-clip-toolbox（`mf`）** | 一条命令编排识别/翻译/配音/混音/烧字幕/导出/质检 | 本组织仓库 `ai-clip-toolbox`（按 tag 固定版本） |
| **D剪（djian）** | 时间线剪辑面板，人可见可改 | `ai-clip-toolbox/djian/`（上游 submodule，锁定提交，不 fork） |
| **D剪 × DSH NEXT 适配插件** | 让 D剪 能在 DSH 里当编辑面板用 | `ai-clip-toolbox/adapters/djian-dsh-next/` |
| FFmpeg | 所有转码与烧字幕的底座 | 系统包管理器安装 |

### 按需装

| 组件 | 用途 | 说明 |
|---|---|---|
| Edge TTS | 配音（本地跑，快、免费） | `mf tts` 默认用它，不需要显卡 |
| Remotion | 片头/包装渲染 | Node 环境，`mf` 调起 |
| faster-whisper（small/tiny） | 断网时临时识别 | 主用 `large-v3` 在 GPU 机上，本地小模型只做兜底 |

### 不装（重要）

**员工机不装 torch、不装大模型、不下载 whisper large-v3。**
这些都在 GPU 机器上，员工机只发请求、收结果。理由：模型动辄几 GB，员工机配置不一，装一次坏一次。

### 安装与自检

```bash
# 1. 拉仓库（固定版本）
git clone <ai-clip-toolbox> && cd ai-clip-toolbox && git checkout <tag>
# 2. 装依赖（uv）
uv sync
# 3. 自检：会告诉你本机工具与远程 GPU 是否通
mf health
# 4. 建工程（必须带品牌）
mf new 点胶对比 -b 品硕
```

工程、素材、成品都在 `~/媒体库`；需要 GPU 的步骤由 `mf` 自动转发到 GPU 机器并把结果取回，**员工不需要手动调接口**。

## 二、需要显卡的部分（远程 GPU）

| 能力 | 现状 | 走哪 |
|---|---|---|
| 语音识别（ASR，large-v3） | ✅ 可用 | `mf asr` → `worker.py asr` |
| 人声分离（demucs） | ✅ 可用 | `mf sep` → `worker.py sep` |
| 翻译（ollama qwen2.5） | ✅ 可用 | `mf translate` |
| 配音（Edge TTS） | ✅ 可用（不耗显卡） | `mf tts` |
| GPT-SoVITS 克隆音色 | ⛔ 未装 | 规划中 |
| **视频生成（文生视频/图生视频）** | ⛔ 未装（缺 ComfyUI + 模型） | 规划：ComfyUI + LTX-Video / Wan2.1-T2V-1.3B（12GB 显存可跑） |

接口、探测与实测见 [`远程显卡接口.md`](远程显卡接口.md)。

## 三、边界与红线

- 品牌隔离：品硕、晖华素材不混用，工程必须带 `-b`
- 素材不遮原片中文硬字幕；目标语字幕只压最底部小字
- 我方只做内容生产，不代企业报价、不承诺交期
