# 远程显卡接口（huoke 网站 ↔ GPU 机器）

## 机器

| 项 | 值 |
|---|---|
| 主机 | Win `l-l`（Tailscale `100.79.151.52`） |
| 显卡 | RTX 4080 Laptop 12GB（CUDA 可用） |
| 运行目录 | `C:\mediagpu\{venv,bin,models,jobs,logs}` |
| Python | `C:\mediagpu\venv\Scripts\python.exe`（torch / faster-whisper / demucs） |
| 网关 | `C:\mediagpu\bin\gpuw.mjs`（Node，**只绑 `127.0.0.1:18700`**） |
| 守护 | 计划任务 `huoke-gpuw`（循环拉起）+ `huoke-netguard` 每 5 分钟查 18700 |

## 两层接口

```
员工机 mf  ──SSH──►  worker.py（asr / sep / sovits）
浏览器 / agent ──HTTPS──► huoke-app /api/gpu/*  ──本机──►  gpuw 18700  ──► worker.py
```

- `huoke-app` 只做鉴权 + 转发 + 审计，不跑模型
- 面板入口：**内容生产**（`/media`），管理员提交，员工只读

## 网关接口（127.0.0.1:18700，不对外）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/caps` | 能力探活：asr / sep / tts_edge / translate_ollama / video_comfyui / sovits |
| GET | `/jobs` | 最近 30 个任务状态 |
| POST | `/jobs` | `{kind:"asr"\|"sep"\|"tts"\|"video", input?, text?, voice?, language?, model?}`，同步跑完再返回 |
| GET | `/logs?id=` | 任务日志尾部 4KB |

任务产物在 `C:\mediagpu\jobs\<任务id>\`（`job.json` / `status.json` / `log.txt` / 输出文件）。

## 网站接口（huoke-app，需登录或 agent 令牌）

```bash
# 登录态（浏览器 cookie）
curl -b cookie.txt https://hub.bairui.site/api/gpu/caps

# agent 令牌
curl -H "Authorization: Bearer hk_xxx" https://hub.bairui.site/api/gpu/caps

# 提交识别
curl -H "Authorization: Bearer hk_xxx" -H 'content-type: application/json' \
  -d '{"kind":"asr","input":"C:\\mediagpu\\jobs\\demo.mp4","language":"zh"}' \
  https://hub.bairui.site/api/gpu/jobs
```

| 方法 | 路径 | 谁能用 |
|---|---|---|
| GET | `/api/gpu/caps` | 登录用户 + agent |
| GET | `/api/gpu/jobs` | 登录用户 + agent |
| GET | `/api/gpu/log?id=` | 登录用户 + agent |
| POST | `/api/gpu/jobs` | 管理员 + agent（staff 禁止） |

每次提交写审计 `gpu:<kind>`。

## 任务类型

| kind | 参数 | 产物 |
|---|---|---|
| `asr` | `input` 服务器路径、`language`、`model`（默认 large-v3） | `out.srt` |
| `sep` | `input` | `sep/` 下的人声与伴奏 |
| `tts` | `text`、`voice`（默认 zh-CN-XiaoxiaoNeural） | `out.mp3` |
| `video` | `prompt` | 现在回「ComfyUI 没起来（视频生成未安装）」，装机后接工作流 |

## 实测（2026-11-12）

```
edge-tts 生成 "品硕自动化，点胶机与灌胶设备制造商。" → 4.46s 音频
POST /api/gpu/jobs {kind:asr, language:zh, model:large-v3} → 3.31s 完成
输出：品硕自动化、点焦机与灌焦设备制造商（点胶/灌胶 被识别成同音字，属正常）
```

## 视频生成怎么接（下一步）

1. GPU 机装 ComfyUI（`127.0.0.1:8188`）+ 一个视频模型（LTX-Video 或 Wan2.1-T2V-1.3B，12GB 可跑）
2. `gpuw.mjs` 的 `/caps` 会自动探测到 `video_comfyui: true`
3. 在 `startJob` 加一个 `kind:"video"` 分支，POST 到 ComfyUI 的 `/prompt`，产物落 `jobs\<id>\out.mp4`
4. 面板「内容生产」会自动显示「🎥 视频生成 可用」，接口不变

> 现在这块显示"未装"，是因为机器上确实没有 ComfyUI —— 不是接口没做。
