# content · 内容生产

拍什么、说什么、按什么顺序说，在这里定；怎么剪在仓库根目录（`mf` + 剪辑规范 + `shots/`）。

## 一条选题的生命周期

```
content/calendar/选题.csv        选题（品牌/平台/角度/状态/编号）
      ↓ 认领
content/scripts/<选题>.md        脚本 + 分镜（口播、镜头、字幕要点、CTA）
      ↓ mf new
~/媒体库/工程/<日期>-<名称>/      素材与工程（不进 git）
      ↓ D剪 面板剪
~/媒体库/成品/<品牌>/<工程>/<平台>/  成片与封面（不进 git）
```

## 硬规则（写脚本前先看）

1. **品牌隔离**：一条内容只属于一个品牌，两个品牌不互相导流、不共用素材目录。
2. **不报价、不承诺交期**：客户问价统一回「厂家工程师按样品/图纸评估后报价」。
3. **不用绝对化用语**：最、第一、唯一、100%、零误判 —— `huoke_lint.py` 会拦。
4. **画面与文案都不留联系方式**：电话、微信、二维码、邮箱、网址一律不出现；国内只用官方留资组件。
5. **AI 生成内容要标识**：画面/配音由 AI 生成的，结尾小字标识，发布时勾平台 AI 声明。
6. **CTA 固定**：中文「发样品照片/图纸，免费评估方案」；英文 "Send us your part photos or drawings for a free evaluation."

规则的可执行版本在 `docs/剪辑规范.md` §9（机器参数块），改规则只改那个文件。
